Mit MA OBS MediaLink kannst du OBS Studio aus grandMA3 über sACN steuern. Szenenwechsel, Bildüberblendungen sowie Video- und Audiosteuerung folgen dabei den OBS-Cues einer festgelegten grandMA3-Sequenz.

**OBS-Plugin v0.45 BETA · grandMA3-Plugin v0.42 BETA**

## Downloads

| Datei | Verwendung |
| --- | --- |
| **MA_OBS_MediaLink_v045_Setup_x64.exe** | Empfohlene Installation für normales OBS Studio 33 unter Windows x64; Update und Deinstallation enthalten |
| **MA_OBS_MediaLink_v045_Windows_x64.zip** | Alternative zur manuellen Installation der Plugin-DLL und des Shaders |
| **MA_OBS_MediaLink_MA042.zip** | grandMA3-Plugin, beide GDTF-Fixtures und MA-Anleitungen; separat importieren |
| **MA_OBS_MediaLink_v045_MA042_Source.zip** | Zugehöriger vollständiger Repository-Quellstand der Binärpakete |
| **SHA256SUMS.txt** | Prüfsummen für Setup, Windows-ZIP, MA-ZIP und Quellcode-ZIP |

Für die Installation unter Windows empfehle ich die Setup-Datei. Das MA-Paket brauchst du zusätzlich für den Import in grandMA3. Die von GitHub automatisch angebotenen Quellcode-Downloads sind für die normale Installation nicht erforderlich.

## Installation und erster Start

1. Schließe OBS vollständig. Sichere bei einem Update vorher deine OBS-Konfiguration und den bisherigen Pluginordner.
2. Führe das Windows-Setup aus und wähle deinen OBS-Hauptordner aus, normalerweise `C:\Program Files\obs-studio`.
3. Starte OBS und öffne **Werkzeuge → MA OBS MediaLink**. Eine zusätzliche Crossfade-Quelle in einer Szene brauchst du nicht.
4. Entpacke das **MA042-ZIP**. Importiere das grandMA3-Plugin über die zusammengehörigen XML-/Lua-Dateien und importiere und patche die Fixtures **MA OBS MediaLink Fade** und **MA OBS MediaLink Steuerung**.
5. Gleiche Universum und Startadresse auf beiden Seiten ab. Die Fixtures belegen gemeinsam zehn aufeinanderfolgende DMX-Adressen im selben Universum.

Das Setup installiert nach `%ProgramData%\obs-studio\plugins\obs-sacn-crossfade`. Prüfe vorab, ob noch ältere MediaLink-Kopien in anderen Pluginordnern liegen, und entferne sie, damit OBS das Plugin nur einmal lädt. Bei der Deinstallation über Windows bleiben deine MediaLink-Regeln und deine OBS-Konfiguration erhalten.

Die Cue-Note `OBS:1` ruft die erste Szene deiner OBS-Szenenliste auf. Speichere das Fade-Preset ausdrücklich in Cue Part 0. Wenn du die Szenenreihenfolge in OBS änderst, ändern sich auch die Szenennummern.

## Inhalt dieser Beta

- Steuerung von OBS-Szenen, Video und Audio über die vorhandene grandMA3-Bridge.
- Bild- und Tonfades einschließlich unterbrochener Überblendungen sowie Audioregeln für native Blackmagic-Device-Eingänge.
- Szenenliste und Diagnose im Dock, einzeln speicherbar.
- Windows-Installer mit Erkennung von OBS 33, Prüfung auf laufendes OBS, Aktualisierung und Deinstallation.
- Separate Downloadpakete für Windows und grandMA3/Fixtures sowie nachvollziehbare Buildinformationen.

Fixture-Typ-IDs und Kanalbelegung bleiben gegenüber den ursprünglichen Profilen unverändert. Die Fixture-Namen lauten **MA OBS MediaLink Fade** und **MA OBS MediaLink Steuerung**.

## Teststand

Ich habe diese Beta mit **OBS Studio 33.0.1** und **grandMA3 2.5.0.3** in meinem Aufbau getestet. Auch die saubere Installation auf einem zweiten Rechner **ohne Entwicklerwerkzeuge** hat funktioniert.

| Prüfung | Ergebnis |
| --- | --- |
| Steuerungs- und MA-Tests im GitHub-Workflow | Erfolgreich |
| Vollständiger Windows-x64-Build gegen OBS-SDK 33.0.0 / Qt 6.11.1 | Erfolgreich |
| Zwölf automatisierte Installerszenarien mit künstlichem OBS-Testprogramm | Erfolgreich, einschließlich Windows-Registrierung und Erhalt fremder Dateien |
| Saubere Erstinstallation auf dem Hauptrechner | Erfolgreich getestet |
| Installation auf einem zweiten Rechner ohne Entwicklerwerkzeuge | Erfolgreich getestet |
| Erneute Installation desselben Pakets, Einstellungen, Deinstallation/Neuinstallation und bisheriger Praxistest | Erfolgreich getestet |

Meine Tests beziehen sich auf diesen Aufbau. Andere OBS-, grandMA3-, Windows- und Hardwarekonfigurationen habe ich damit nicht pauschal geprüft. Auch ein Update von jeder älteren MediaLink-Version habe ich nicht einzeln getestet. In den Downloadpaketen findest du teilweise noch Hinweise zum Teststand beim Build. Die hier aufgeführten manuellen Tests habe ich anschließend abgeschlossen.

## Bekannte Einschränkungen

- Beta-Version für normale OBS-33-Installationen unter Windows x64. Das Setup unterstützt keine portablen OBS-Installationen, Windows x86 oder Windows ARM64.
- Das Setup besitzt noch kein Herausgeberzertifikat; Windows kann einen Hinweis auf den unbekannten Herausgeber anzeigen.
- grandMA3-Plugin und Fixtures werden aus dem separaten MA-Paket importiert. Das Windows-Setup installiert sie noch nicht lokal mit.
- Zusätzliche manuell installierte Plugin-Kopien an anderen Pfaden werden nicht automatisch entfernt.
- Native Blackmagic-Audioregeln gelten für den OBS-Quellentyp **Blackmagic Device** (`decklink-input`).
